# Nairaland themes

This directory contains the original archived Nairaland replica and a separate fallback variant.

- `theme.txt` is the restored **BUZZ NAME REPLICA v14** payload. It is the exact archived payload captured before the later compact-theme experiments, including its homepage, topic, profile, featured-content, and ad-slider behavior. It uses the marker `nl-theme-marker:nairaland` and corresponds to customer file `15535.txt`.
- `theme-v2.txt` is the separate compact/fallback variant. It uses the marker `nl-theme-marker:nairaland_v2` and corresponds to customer file `95151.txt`, exposed in the selector as **Nairaland Plus**.

The original v14 payload is intentionally kept intact. Do not append the compact fallback or replace its markup when updating the original theme.
